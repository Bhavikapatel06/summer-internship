# 🚀 Summer Internship Project – AIA Engineering Limited

This repository contains my Summer Internship project completed at **AIA Engineering Limited**.

## 📌 Project

**AI-Powered Automated Recruitment System (ATS)**

The Automated Recruitment System is a full-stack web application that helps automate the recruitment process. It allows organizations to manage manpower requests, job openings, candidate applications, interview stages, and hiring through a role-based system.

## ✨ Features

* 📝 Manpower Request (MRF) Management
* ✅ Approval Workflow
* 👨‍💼 Candidate Management
* 📊 Recruitment Dashboard
* 🔄 Applicant Tracking Pipeline
* 🎯 Automatic Vacancy Fulfillment
* 🔐 Role-Based Authentication

## 🛠️ Technology Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication
